# Shopee reference patterns

Reviewed 26 October 2026. SaleSync adapts public workflow patterns; it is not connected to Shopee, and these links do not establish access to its private administrative UI or APIs.

| Pattern used | Public reference |
| --- | --- |
| Product variation selection, cart and checkout progression | [Shopee Help Center: purchasing items](https://help.shopee.ph/portal/4) |
| Return reasons, evidence, review and dispatch instructions | [Shopee PH: effective supporting return/refund evidence](https://help.shopee.ph/portal/4/article/81183-%5BReturn-Refund%5D-What-are-the-effective-supporting-documents-I-can-submit-as-evidence-for-my-refund%2Freturn-request%3F-%28ENG%29?previousPage=other+articles), [original/sealed-item return request](https://help.shopee.ph/portal/4/article/97775-) |
| Separate seller, platform and shipping voucher selection | [Shopee SG: voucher types and stacking](https://help.shopee.sg/portal/4/article/76513-%5BVouchers%5D-What-vouchers-are-there-on-Shopee), [Shopee PH seller introduction: shipping voucher subsidy](https://shopee.ph/m/sell-on-shopee) |
| Pickup selected as a shipping option with a location confirmation | [Shopee SG: Collection Points selection](https://help.shopee.sg/portal/4/article/81808-%5BCollection-Points%5D-What-is-Collection-Point-and-how-to-select-it-as-my-delivery-option) |
| Seller order operations, account addresses, performance and Business Insights | [Shopee Philippines: sell on Shopee](https://shopee.ph/m/sell-on-shopee) |

The pickup reference is from Singapore. SaleSync implements a configurable **store-pickup adaptation**, not a claim that Shopee PH offers these same locations or terms. Voucher windows, caps and rules are SaleSync settings. Return eligibility and deadlines are configurable local policies rather than a promise of current Shopee policy.

Account suspension review, application assessment, seller explanation cases, the Management Activity Log, report documents and the backend API proposal are SaleSync designs based on the requested requirements. No private Shopee Management screen was copied or represented as verified.
