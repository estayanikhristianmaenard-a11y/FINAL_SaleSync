# Release notes — 26 October 2026

Updated the existing project and regenerated the same standalone HTML and four portal pages.

The release adds an overall inbox, redesigned account and authentication screens, named addresses, pickup, stacked shipping/platform/shop vouchers, itemized invoices, return evidence and tracking, seller review and appeals, Management refund authorization, reasoned suspensions, application review and seller-response listing moderation.

Seller has six primary modules, including Messages. Management has nine and Maintenance seven. Common workspace headings are compact; repeated introductions, testing strips and retired presentation labels are removed from the main workflows. The homepage carousel is manual, category icons are consistent SVGs, left filters narrow the selected category, and the comparison screen omits its launch tray and groups unlike types.

Retained 280 product records and archived 139 duplicated editions/source repetitions, leaving 141 visible records. Imported 152 additional manufacturer gallery views across 51 selections; replaced five low-quality opening product photographs with model-specific pictures and matching listing titles. Variant labels, attributes, prices and image choices are editable. Seller uploads and customized titles are preserved by migrations.

Four seeded testing accounts are enabled. Retained merchant/contact records cannot sign in through the login form. Testing credentials are in TEST_ACCOUNTS.txt. The package contains source, assets, checks and the backend handoff contract; local payment/courier/email adapters remain disconnected from live services.
